# 主题与外观 · Skin

DSH Web 插件：给整个界面换肤，可选插画壁纸，还有一只可以放到 Windows 桌面上常驻的小桌宠。

## 功能

- **13 套配色皮肤**（含 5 套办公风）+ 自定义色表盘，作用于聊天区、侧栏、输入框、消息和代码块。
- **壁纸**：12 张插画（`gpt-image-2` 生成）+ 3 张纯 CSS 纹理（不占体积、断网可用），可调不透明度与铺法。
- **跨插件换肤契约**：其他插件可以读取当前皮肤，跟着一起换。
- **三页签面板**：主题 / 壁纸 / 桌宠各自独立。
- **9 种桌宠角色**：网页浮窗版支持右键菜单、甩动、任务完场播报；Windows 上还可以常驻桌面。

## 安装

本仓库是运行产物加三份无浏览器测试组成的发布快照，入口可直接运行，无需构建。

```powershell
dsh plugin --profile <你的-profile> add "dsh-plugin-skin@0.7.0"
```

装完按宿主提示刷新或重启。桌面常驻桌宠是单独开关，不启用也不会影响网页端换肤。

## 数据与权限

- 换肤设置存在当前浏览器的 `localStorage["dsh-skin:appearance"]`。
- 壁纸与桌宠素材由插件自己的路由 `/dsh-skin/` 从包内读取，不外链、不联网。
- 桌面常驻桌宠会在你明确启用后，用本机 PowerShell + WPF 起一个进程，并在 `~/.dsh-skin/` 读写配置、状态和窗口位置。
- 桌宠不联网：她说的每句话都来自本地语料。
- 不注册宿主路由以外的服务，不写入业务目录，不把界面数据上传到外部服务。

## 已知限制

- 仅中文界面，面向 DSH Web。
- **桌面常驻桌宠仅 Windows**（PowerShell + WPF）；其他系统只能用网页浮窗版。
- 壁纸模式会降低背景表面不透明度让壁纸透出来，文字可读性依靠额外的实心兜底层保证。
- 尚未宣称特定 DSH 版本范围的兼容保证，也未在干净 profile 中完成安装验收。

## 验证

需要 Node.js >=18，测试不需要浏览器：

```powershell
npm run verify
npm pack --dry-run --ignore-scripts
```

最近一次结果：client-harness 247 项、pet-content 445 项、host-route 45 项，合计 **737 项通过**。
单测与假 DOM 测试不替代真实 DSH 的浏览器安装验收。

## 素材与授权

- 包内 12 张插画壁纸均为 `gpt-image-2` 生成。
- 原生「黄昏彩虹」「紫发工作台」两张属本地个人使用的同人图，**无公开再分发许可，已从发布包移除**（留在开发者本机的 `assets-local/`，不在本仓库）。
- 桌宠角色为原创几何与原创形象，不含商业 IP 角色。
- 包件的 MIT 授权针对作者有权授权的代码；第三方素材权利仍归各自权利人。

## 分发边界

npm 包里只包含运行入口、`cordis.patch.yml`、运行时素材（`assets/*.webp`、`assets/pet-desktop-*.png`）、桌面脚本和 README。
素材生成目录、图集 `*-sheet.png`、`assets/cursors/`、`default-wallpaper.png` 和 `verify/` 都不随包发布 —— 包体因此约为 8 MB，而不是 86 MB。
